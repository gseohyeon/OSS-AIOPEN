## 배운 내용

프로젝트 아이디어를 제안할 때에는 필요한 기능뿐만 아니라 개발 기간과 구현 범위를 함께 고려해야 한다는 점을 배웠다. 학습 일정 관리 웹앱을 구상하면서 우선 구현할 기본 기능과 여유가 있을 때 추가할 기능을 구분하고, 서버 없이 데이터를 저장하는 방식으로 초기 개발 범위를 줄이는 방법을 생각해 보았다.

또한 팀원마다 서로 다른 아이디어와 선호가 있기 때문에 의견을 요청하고 최종 후보를 선택하는 과정이 필요하다는 점을 알게 되었다. GitHub 개인 활동 파일 작성과 Commit 절차를 안내받으며, 각자가 수행한 내용을 자신의 계정으로 꾸준히 기록하는 것이 중요하다는 점도 배웠다.
