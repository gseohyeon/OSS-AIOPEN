# 9주차 팀 회의

## 참석자

- 김서현
- 김시훈
- 홍현택
- 박정인
- 최유찬

## 회의 주제

점메추 프로그램의 본격적인 개발을 시작하기 위해 팀원별 역할을 확정하고, 각 역할의 구체적인 업무와 GitHub를 통한 활동 기록 방법을 논의하였다.

## 회의 내용

### 1. 프로젝트 개발 방식 논의

이전 회의에서 점메추 프로그램의 주제와 기본적인 기능, Python을 개발 언어로 사용하는 방향을 결정하였다.

이번 회의에서는 실제 개발을 시작하기에 앞서 팀원별 역할을 구체적으로 나누기로 하였다.

김서현 팀장은 프로그램의 전체 구조를 직접 개발하고 각 팀원이 제공하는 데이터와 자료를 최종 프로그램에 통합하는 방식으로 진행하는 방안을 제시하였다.

이에 따라 모든 팀원이 각각 프로그램 코드를 작성하는 방식보다는, 메인 개발 담당을 중심으로 데이터 조사, API 조사, 기능 테스트 등의 역할을 분담하여 프로젝트를 진행하기로 하였다.

### 2. 역할 구성 제안

김서현 팀장은 프로젝트에 필요한 업무를 다음과 같이 구분하였다.

1. 프로그램 메인 개발 및 전체 기능 통합
2. 추천 데이터 및 추천 기준 정리
3. 외부 API 및 필요한 데이터 조사
4. 정상 기능 테스트
5. 예외 상황 및 오류 유도 테스트

메인 개발 및 전체 통합은 김서현 팀장이 담당하고, 나머지 네 가지 역할은 팀원들의 희망 역할을 먼저 확인한 뒤 배정하기로 하였다.

팀원들이 다른 사람의 선택에 영향을 받지 않고 원하는 역할을 고를 수 있도록 개인적으로 희망 역할을 전달받는 방식으로 의견을 수집하였다.

### 3. 희망 역할 조정

팀원들의 희망 역할을 확인한 결과 여러 명이 같은 역할을 선택하여 역할 조정이 필요하였다.

이에 따라 팀원들과 추가로 의견을 주고받으며 각자의 희망 사항과 수행 가능한 업무를 고려하여 역할을 다시 배분하였다.

팀원들이 서로 역할을 양보하고 다른 업무를 맡는 것에도 동의하여 큰 의견 충돌 없이 최종 역할을 결정하였다.

### 4. 최종 역할 분담

#### 김서현 팀장 - 메인 개발 및 전체 통합

- Python을 이용한 점메추 프로그램 전체 개발
- 프로그램의 기본 구조 및 핵심 기능 구현
- 팀원들이 조사한 데이터와 API를 프로그램에 적용
- 테스트 과정에서 발견된 오류 수정
- 최종 프로그램 통합 및 전체 진행 관리

#### 홍현택 팀원 - 추천 데이터 및 추천 기준 정리

- 점메추 프로그램에서 사용할 음식 및 음식점 관련 데이터 정리
- 음식 종류와 추천에 필요한 기준 조사
- 어떤 조건을 추천 과정에서 사용할지 정리
- 필요한 API 및 데이터 항목을 검토하여 API 담당자와 공유
- 조사한 내용을 GitHub에 문서 형태로 기록

#### 최유찬 팀원 - API 및 외부 데이터 조사

- 프로그램에서 필요한 음식 및 음식점 관련 API 조사
- 공공데이터포털 등을 활용하여 사용 가능한 API 탐색
- 필요한 API Key 발급 및 사용 방법 확인
- 추천 데이터 담당자와 필요한 데이터 항목을 확인하여 적절한 API 선정
- API 및 관련 통계자료 조사 결과를 GitHub에 기록

#### 박정인 팀원 - 정상 기능 테스트

- 개발된 프로그램의 기본 기능이 정상적으로 작동하는지 확인
- 메뉴 추천 기능 및 주요 입력 기능 테스트
- 정해진 사용 방법에 따라 프로그램을 실행하고 결과 확인
- 발견한 문제점과 테스트 결과를 GitHub에 기록
- 수정된 프로그램의 기능을 다시 확인

#### 김시훈 팀원 - 예외 및 오류 테스트

- 정상적인 사용뿐만 아니라 다양한 예외 상황을 만들어 프로그램 테스트
- 잘못된 입력값이나 예상하지 못한 조작을 통한 오류 확인
- 버튼 연속 입력 등 일반적인 사용 과정에서 발생할 수 있는 문제 확인
- 오류 발생 조건과 결과를 정리하여 개발 담당자에게 전달
- 수정 이후 동일한 상황에서 오류가 해결되었는지 재확인

### 5. 테스트 방식 구분

정상 기능 테스트와 예외 및 오류 테스트는 서로 다른 방식으로 진행하기로 하였다.

정상 기능 테스트는 사용자가 프로그램에서 제공하는 기능을 정상적인 방법으로 이용했을 때 의도한 결과가 출력되는지를 확인하는 것을 목적으로 한다.

예외 및 오류 테스트는 잘못된 입력, 반복적인 조작, 예상하지 못한 상황 등을 의도적으로 발생시켜 프로그램이 비정상적으로 종료되거나 잘못된 결과를 출력하는지를 확인하는 방식으로 진행한다.

두 테스트에서 발견된 문제는 김서현 팀장에게 전달하고, 코드 수정 이후 다시 테스트하는 방식으로 진행하기로 하였다.

### 6. API 및 추천 데이터 협업 방식

API 담당자와 추천 데이터 담당자는 서로 필요한 정보를 공유하면서 업무를 진행하기로 하였다.

홍현택 팀원이 추천에 필요한 데이터와 기준을 먼저 정리하고, 이를 바탕으로 최유찬 팀원이 공공데이터포털 등을 조사하여 실제 프로그램에서 사용할 수 있는 API와 데이터를 찾는 방향으로 진행한다.

필요한 API의 종류, 데이터 항목, 조사 결과 등은 문서 형태로 GitHub에 기록하고, 김서현 팀장은 해당 자료를 참고하여 실제 프로그램에 적용하기로 하였다.

### 7. GitHub 활동 기록 방법

각 팀원은 자신의 역할에 따라 수행한 작업을 GitHub에 지속적으로 기록하기로 하였다.

코드 작성뿐만 아니라 데이터 조사, API 조사, 테스트 결과 역시 프로젝트의 중요한 작업으로 보고 Markdown 문서 등을 이용하여 활동 내용을 남기기로 하였다.

각 역할별 자료가 GitHub에 축적되도록 하여 누가 어떤 작업을 수행했는지 확인할 수 있도록 관리한다.
