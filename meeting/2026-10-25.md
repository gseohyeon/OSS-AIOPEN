# 7~8주차 팀 활동 및 간단 회의

## 참석자

- 김서현
- 김시훈
- 홍현택
- 박정인
- 최유찬

## 회의 주제

중간고사 기간 중 프로젝트 진행 상황을 간단하게 확인하고, 점메추 프로그램 개발을 시작하기 전에 필요한 API와 GitHub 협업 방식에 대해 기본적인 방향을 정리하였다.

## 회의 내용

### 1. 중간고사 기간으로 인한 회의 일정 조정

7~8주차는 팀원들의 중간고사 준비 및 시험 일정이 집중되어 있어 이전과 같은 방식의 정식 프로젝트 회의를 진행하기 어려웠다.

이에 따라 해당 기간에는 프로젝트 개발을 본격적으로 진행하기보다는 기존에 결정한 프로젝트 내용을 다시 확인하고, 이후 개발을 시작하기 위해 필요한 사항을 간단하게 정리하는 방식으로 회의를 대체하였다.

프로젝트 주제는 이전 회의에서 결정한 `점메추 프로그램`을 그대로 유지하며, 개발 언어 역시 기존에 결정한 Python을 사용하기로 하였다.

### 2. 점메추 프로그램 기본 방향 재확인

점메추 프로그램은 사용자의 조건에 따라 적절한 점심 메뉴 또는 음식점을 추천하는 프로그램으로 개발한다.

단순히 메뉴를 무작위로 선택하는 방식보다는 최근 먹은 음식, 음식 종류, 이동 가능한 거리, 주변 음식점 등의 정보를 활용해 추천 결과를 제공하는 방향을 유지하기로 하였다.

프로젝트의 세부 기능은 개발 과정에서 구현 가능성을 확인하면서 필요한 경우 조정하기로 하였다.

### 3. 음식 및 음식점 관련 API 조사

점메추 프로그램의 추천 기능을 구현하기 위해 음식 또는 음식점 정보를 제공하는 API가 필요하다는 점을 확인하였다.

이에 따라 공공데이터포털 등을 중심으로 다음과 같은 데이터를 제공하는 API를 조사하기로 하였다.

- 음식점 이름 및 주소
- 음식점 종류
- 음식 또는 메뉴 이름
- 음식 분류
- 영양성분 등의 추가 정보

현재 조사 과정에서 전국 일반음식점 정보와 음식별 영양정보 등을 제공하는 공공데이터가 존재한다는 점을 확인하였다.

다만 실제 프로그램에서 필요한 데이터가 충분히 제공되는지, Python에서 호출하기 쉬운지 등을 추가로 확인해야 하기 때문에 API를 바로 확정하지 않고 9주차에 후보 API를 직접 테스트한 뒤 사용할 데이터를 결정하기로 하였다.

### 4. GitHub 협업 방식 기본 방향

GitHub 협업 방식은 팀원들이 같은 파일을 동시에 수정하여 문제가 발생하는 것을 줄이고, 각자의 개발 기록을 확인할 수 있도록 작업을 분리하는 방식으로 진행하기로 하였다.

기본적인 협업 과정은 다음과 같이 정리하였다.

`팀 저장소 확인 → 자신의 작업 영역에서 기능 개발 → 작업 내용 Commit → GitHub에 업로드 → 완성된 기능 확인 → main에 통합`

프로젝트의 `main`은 현재 정상적으로 동작하는 프로그램을 보관하는 공간으로 사용하고, 팀원들은 자신이 맡은 기능을 별도로 작업한 뒤 완성된 내용을 main에 합치는 방향으로 진행한다.

GitHub 사용이 익숙하지 않은 팀원들이 있기 때문에 처음부터 복잡한 협업 방식을 적용하기보다는 기본적인 Commit과 기능별 작업 분리를 먼저 사용하고, 필요할 경우 Branch와 Pull Request를 활용하기로 하였다.

구체적으로 누가 어떤 기능을 담당하고 어떤 방식으로 GitHub에 파일을 올릴지는 역할 분담과 함께 9주차 회의에서 최종 결정하기로 하였다.

## 결정 및 정리 사항

- 7~8주차는 중간고사 기간으로 인해 정식 회의 대신 간단한 진행 상황 확인 회의로 대체하였다.
- 프로젝트 주제는 `점메추 프로그램`으로 유지한다.
- 개발 언어는 `Python`을 사용한다.
- 음식 및 음식점 데이터를 얻기 위한 공공 API를 조사한다.
- 공공데이터포털에서 음식점 및 음식 관련 API 후보가 확인되어 실제 활용 가능성을 추가로 테스트한다.
- GitHub에서는 팀원별 작업을 분리하고 Commit을 통해 개인 활동 기록을 남기는 방향으로 협업한다.
- 역할 분담은 중간고사가 종료된 이후인 9주차 회의에서 확정한다.
- 사용할 API와 구체적인 GitHub 협업 방법 역시 9주차 회의에서 우선적으로 결정한다.

## 9주차 우선 논의 사항

중간고사 종료 후 바로 개발을 시작할 수 있도록 9주차 회의에서는 다음 사항을 우선적으로 결정하기로 하였다.

- 팀원별 개발 역할 확정
- 공공데이터 API 후보 테스트 및 최종 API 선정
- GitHub 작업 방식 확정
- 개발 파일 구조 결정
- 기능별 개발 일정 정리

위 사항들은 실제 프로그램 개발을 시작하기 위해 필요한 내용이므로 9주차 회의에서 우선적으로 논의하고 빠르게 결정하기로 하였다.
